# Al-Shorouk bilingual site

Static GitHub Pages update. English is at the site root and Arabic is at /ar/. The visible language button switches between the two routes. The embedded logo, project photography, existing visual design, and contact behavior are retained.

The current repo publishes from the root of a branch. This bundle is intended for the isolated bilingual-arabic branch. Review both routes on the Pages preview after selecting that branch as the publishing source.

The existing single-page site has no article renderer. content/articles.json provides a bilingual content scaffold with an article ID and localized slug, title, description, and body. Wire it into article pages and sitemap generation when an article section is added.
